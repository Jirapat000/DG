# ต้นแบบ DrainWatch ทำงานต่อเนื่อง

สเก็ตช์ `full_system.ino` สำหรับ AI Thinker ESP32-CAM เชื่อมกล้อง Float และ Flow ในบอร์ดเดียว ทำงานตลอดเวลาและไม่เข้า deep sleep

| อุปกรณ์ | GPIO | ค่าเริ่มต้น |
|---|---:|---|
| Float switch | 14 | ต่อ GND เมื่อตรวจพบน้ำ (active LOW) |
| Flow pulse | 13 | 450 pulse/L เป็นค่าเริ่มต้น ต้องสอบเทียบ |
| Flash LED | 4 | ปิดตอนบูต สั่งเปิด/ปิดจาก dashboard ได้ |

GPIO13/14 ใช้ร่วมกับ microSD ไม่ได้ สัญญาณเซนเซอร์ต้องไม่เกินแรงดันที่ ESP32 รับได้ หาก Flow ส่งสัญญาณ 5V ต้องปรับระดับสัญญาณก่อน

- เมื่อ Float ตรวจพบน้ำ กล้องถ่ายทันทีและถ่ายซ้ำทุก 5 นาทีตราบที่ยังพบน้ำ
- ส่งสถานะเซนเซอร์/กล้องทุก 5 วินาที และรับคำสั่งถ่ายภาพ/เปิดปิดแฟลชจากเว็บเมื่อออนไลน์
- การวิเคราะห์ภาพและแจ้งเตือน LINE ทำที่ backend เมื่อเข้าเงื่อนไข; ค่าการไหลเป็นศูนย์ขณะ Float แห้งจะไม่ส่งสถานะ `no_flow` ไปสร้างแจ้งเตือนผิด
- โหมดนี้ใช้ไฟต่อเนื่อง และแฟลชเริ่มต้นปิดเพื่อลดโหลดขณะบูต

## อัปโหลดและตรวจผล

1. ตรวจ `secrets.h` ในโฟลเดอร์นี้ให้มี Wi-Fi 2.4 GHz และ device token ตรงกับ Render เก็บไฟล์นี้เป็นความลับ
2. เปิด `full_system.ino` ใน Arduino IDE เลือก AI Thinker ESP32-CAM และพอร์ต COM
3. ปิด Serial Monitor ก่อนอัปโหลด ต่อ GPIO0 ลง GND ระหว่างอัปโหลด แล้วถอด GPIO0 จาก GND และกด RESET
4. เปิด Serial Monitor 115200 baud ตรวจ `CAMERA: ready`, `Wi-Fi connected`, `TELEMETRY: HTTP 200` และสถานะ Float/Flow
5. เปิด dashboard; สถานะออนไลน์ขึ้นเมื่อ backend ได้รับ telemetry ไม่ต้องกดยืนยัน sleep ใน firmware รุ่นนี้

หากขึ้น `Brownout detector was triggered` ให้ตรวจแหล่งจ่าย 5V สาย และจุดต่อไฟก่อน; โค้ดไม่สามารถชดเชยแรงดันตกได้ ตรวจทิศทาง Float และสอบเทียบ `FLOW_PULSES_PER_LITER` ก่อนใช้งานจริง
