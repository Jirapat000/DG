# เฟิร์มแวร์ระบบเต็ม DrainWatch

สำหรับบอร์ด **AI Thinker ESP32-CAM (ESP32 รุ่นคลาสสิก)** ต่อกล้อง, ลูกลอย 52 มม., และ flow meter แบบ pulse เข้าบอร์ดเดียวกัน กล้องและเซนเซอร์ส่งข้อมูลขึ้น API ผ่าน Wi‑Fi; ไม่ต้องต่อ USB กับคอมพิวเตอร์หลังอัปโหลด และไม่ใช้ microSD

## ผังสัญญาณ

| อุปกรณ์ | GPIO | ค่าเริ่มต้นในโค้ด |
|---|---:|---|
| Float switch | 14 | Active LOW: สวิตช์ต่อลง GND เมื่อน้ำยกลูกลอย |
| Flow meter pulse | 13 | YF-S201 class, 450 pulse/L โดยประมาณ |
| Flash LED บนบอร์ด | 4 | กระพริบ 2 ครั้งเมื่อบูต จากนั้นปิด; เปิด/ปิดได้จาก dashboard เมื่อบอร์ดออนไลน์ |
| ปุ่มปลุก (ทางเลือก) | 14 | ปุ่ม NO ต่อขนานกับ Float ระหว่าง GPIO14 กับ GND |

GPIO13/14 ใช้ได้เมื่อไม่ใช้ช่อง microSD ของ ESP32-CAM และ GPIO14 เป็น RTC GPIO สำหรับปลุกจาก deep sleep ค่า active level ของลูกลอยและ pulse/L ต้องตรวจและปรับให้ตรงกับรุ่นจริงก่อนติดตั้ง สัญญาณเข้า ESP32 ห้ามเกิน 3.6 V; ถ้า output ของ flow meter เป็น 5 V ให้ใช้ level shifter/วงจรแบ่งแรงดัน หรือยืนยันว่าเป็น open-collector แล้ว pull-up ไป 3.3 V เท่านั้น

แหล่งจ่าย AI Thinker ESP32-CAM ควรจ่าย 5 V ที่นิ่งและรองรับกระแสพีกประมาณ 1 A ขึ้นไป; ห้ามจ่ายแบตเตอรี่ 5 V เข้าขา 3V3 การกะพริบแฟลชเป็นโหลดชั่วขณะ หากบอร์ดรีเซ็ตตอนแฟลชหรือ Wi‑Fi หลุด ให้ลองแหล่งจ่าย 5 V กระแสสูงขึ้นและสายสั้นก่อนเปลี่ยนฮาร์ดแวร์ส่วนอื่น

## ลำดับทำงาน

- ขณะทำงาน: อ่าน Float/Flow ทุก 5 วินาที ส่งสถานะขึ้น API และ polling คำสั่งแฟลช/ถ่ายภาพจากเว็บ
- เมื่อเปิดไฟหรือถูกปลุกจากลูกลอย: แฟลช GPIO4 กระพริบ 2 ครั้งเป็นสัญญาณเริ่มบอร์ดแล้วดับ และรีเซ็ตการยืนยัน sleep ของรอบก่อนหน้า
- หลังบอร์ดขึ้นออนไลน์ ผู้ใช้ต้องกด **ยืนยันพร้อมทำงาน** บน Dashboard หนึ่งครั้งต่อการบูต/ปลุก; หากยังไม่ยืนยัน ระบบจะทำงานต่อและบล็อก deep sleep
- ถ้า Float ตรวจพบน้ำ: ถ่ายและส่งภาพทันที แล้วถ่ายซ้ำทุก 5 นาทีตราบที่ลูกลอยยังตรวจพบน้ำ
- หลังยืนยันแล้ว ถ้าไม่มีน้ำและไม่มี pulse จาก Flow ต่อเนื่อง 10 นาที: ส่งสถานะ `deep_sleep`, ปิดแฟลช/กล้อง/Wi‑Fi แล้วเข้าสู่ deep sleep
- ลูกลอยปิดวงจร GPIO14 ลง GND เมื่อน้ำขึ้น: ปลุกบอร์ดและเริ่มทำงานใหม่
- deep sleep ปิด Wi‑Fi จึงกดสั่งถ่าย/เปิดแฟลช/ปลุกจากเว็บไม่ได้จนกว่าลูกลอยจะปลุกบอร์ด; คำสั่งแฟลชที่ตั้งไว้บนเว็บจะมีผลหลังอุปกรณ์ตื่น

## เตรียมและอัปโหลด

1. คัดลอก `firmware/esp32_cam/secrets.h` ที่ตั้งค่าจริงแล้วมาไว้ข้าง `full_system.ino`; หากยังไม่มี ให้คัดลอก `firmware/esp32_cam/secrets.h.example` แล้วกรอก Wi‑Fi และ device token ให้ตรงกับ Render
2. เปิด `full_system.ino` ใน Arduino IDE; เลือกบอร์ด **AI Thinker ESP32-CAM** และพอร์ต COM
3. ตั้ง USB-to-Serial ที่ 5V, GND, TX→U0R, RX→U0T; ต่อ GPIO0 ลง GND เพื่ออัปโหลด แล้วถอด GPIO0 และกด RESET
4. เปิด Serial Monitor `115200 baud`; ตรวจ `BOOT SIGNAL: flash blink 2x`, `Wi-Fi connected`, `SLEEP GUARD: reset` และ `TELEMETRY: HTTP 200`
5. เปิด Dashboard; รอขึ้น **เชื่อมต่อแล้ว** แล้วกด **ยืนยันพร้อมทำงาน** สถานะน้ำ/Flow จะอัปเดตทุก 5 วินาที
6. หากยังออฟไลน์ ให้ตรวจ log: `HTTP 401` คือ device token ไม่ตรง, `HTTP 404` คือ device ID/route ไม่ตรง, `HTTP 503` คือ server ยังไม่ได้ตั้งค่า token; `Camera init failed` ชี้ไปที่กล้อง/สายแพ ส่วนรีบูตหรือ Wi‑Fi หลุดตอนแฟลชให้ตรวจไฟเลี้ยงก่อน

## ปรับค่าตามฮาร์ดแวร์

แก้ `FLOAT_WATER_LEVEL` ให้ตรงกับ NO/NC ของลูกลอย และแก้ `FLOW_PULSES_PER_LITER` ตาม datasheet/การสอบเทียบด้วยปริมาตรที่วัดจริง ก่อนใช้ค่าน้ำไหลเป็นเกณฑ์ตัดสิน หากใช้บอร์ด ESP32 รุ่นอื่น ให้ตรวจ pinout และ RTC GPIO ของชิปนั้นก่อน เพราะผัง GPIO นี้ระบุสำหรับ AI Thinker ESP32-CAM เท่านั้น
